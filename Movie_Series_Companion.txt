MOVIE & SERIES COMPANION AGENTMOVIE & SERIES COMPANION AGENTABSTRACTThe Project is entitled “MOVIE & SERIES COMPANION AGENT.” Entertainment is a major part of student life, yet keeping track of what has been watched, remembering details of ongoing series, and finding new recommendations can quickly become overwhelming. Generic streaming platforms often repeat suggestions, overlook personal preferences, or fail to provide engaging interactivity. This project proposes a personalized companion agent that not only remembers what users have watched and enjoyed but also enhances the viewing experience with recaps, recommendations, and interactive activities.The system is designed using the Google Agent Development Kit, with MongoDB serving as its memory layer for storing records of watched shows, likes, dislikes, and partial progress in ongoing series. When the user requests recommendations, the agent combines this stored history with results from free web searches or open APIs to suggest fresh, relevant content while avoiding previously rejected or already watched titles. For continuity, the agent generates concise recaps of past episodes, ensuring users can easily re-engage with an ongoing story. To make the system more engaging, it also introduces lightweight interactive features, such as quizzes that ask the user to identify characters from stored quotes or fun facts. Together, these functions create a dynamic entertainment assistant that blends memory management with reasoning and user interaction.Evaluation will measure how effectively the agent personalizes recommendations, prevents repetitive suggestions, and generates accurate recaps. Additional testing will focus on the usability of its interactive quiz feature and its adaptability in multi-turn interactions, where the agent maintains context across a conversation. The expected outcome is a smart, student-friendly companion that enriches entertainment consumption by demonstrating how structured storage, adaptive reasoning, and conversational engagement can be combined into a single lightweight system without reliance on heavy infrastructure or commercial platforms.SYSTEM SPECIFICATION:HARDWARE SPECIFICATIONProcessor	            	:	Intel Pentium Dual core 2.40 Ghz    		Mother Board		:	MercuryRAM			:	2GBHard Disk		:	320 GBMouse                     	:	Logitech Optical MouseKeyboard		:	Logitech MultimediaSOFTWARE SPECIFICATION                     	Operating System	:       	Windows 7                      	Front-End		:       	Visual Studio.Net 2010 Back End	          	:        	SQL Server 2005 Signature of HOD 						Signature of the GuideRemarks of the Member / Monitoring CommitteeRecommended / Not Recommended 			 Approved / Not ApprovedSignature of Member / Monitoring Committee               	Signature of Head of Monitoring Committee                                                                                     (Name, Designation & Address with seal)
