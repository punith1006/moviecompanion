### 🔴 CRITICAL GAP: Quiz from Stored Quotes

**Abstract says**: "quizzes that ask the user to identify characters from stored quotes or fun facts"

**Current PRD/Plan says**: Generate quiz questions using AI based on show knowledge

**The Problem**:
- Abstract implies we STORE actual quotes from shows
- Current plan generates questions on-the-fly with GPT
- We have NO mechanism to collect, store, or retrieve actual character quotes

**Impact**: This is a CORE differentiator mentioned in the abstract. Without stored quotes, quizzes feel generic rather than personalized.

**Recommended Fix**:
1. Integrate with TMDB/TVmaze for episode quotes (if available)
2. OR use a quotes API (TheySaidSo, IMDB quotes scraping)
3. OR allow users to add their favorite quotes from shows they watch
4. Store quotes in MongoDB with show/character/episode reference
5. Quiz pulls from user's saved quotes + AI-generated trivia

---

### 🟡 CONCERN: "Lightweight System" vs. Current Architecture

**Abstract says**: "lightweight system without reliance on heavy infrastructure or commercial platforms"

**Current Architecture**:
- 3 separate microservices (Frontend, Backend, AI)
- External dependencies: MongoDB, OpenAI API, TMDB API
- Python + Node.js + Next.js stack

**Assessment**: The architecture is reasonable for a real product, but might be over-engineered for the academic project context (based on the hardware specs in the abstract: 2GB RAM, Pentium processor).

**Consideration**: For academic demonstration, could simplify to:
- Single backend (Python FastAPI with all logic)
- Simpler frontend (React without Next.js SSR complexity)
- SQLite instead of MongoDB for easier setup

**Recommendation**: Keep current architecture for quality, but document a "lite" deployment option.

### Quiz Mode - Deeper Analysis

**Current Incentive**: Earn XP and badges

**Problem**: XP means nothing if there's no payoff. Users need:
1. **Social Proof**: Share quiz results ("I got 10/10 on Breaking Bad!")
2. **Comparative Challenge**: "You ranked #47 among Breaking Bad fans"
3. **Tangible Progress**: Unlock titles ("Breaking Bad Expert")
4. **Content Discovery**: Perfect quiz score unlocks "deep cut" recommendations

**What's Missing**:
- Leaderboards (even simple ones)
- Shareable results cards for social media
- Title/badge progression that feels meaningful
- Connection between quiz performance and other features

**Recommendation**: Add to Phase 4:
- Generate shareable image for quiz result
- Simple tier system: Novice → Fan → Expert → Master
- Unlock exclusive recommendation after perfect score

### 🟡 CONCERN: Google ADK Uncertainty

**What We Assume**: Google ADK provides agent orchestration, tool calling, and memory management.

**What We Need to Validate**:
1. Does ADK support custom tools easily?
2. Is there good documentation/examples?
3. What are the API limits/costs?
4. Does it handle conversation context well?

**Recommendation**: Before finalizing plan, spend 30 minutes validating ADK capabilities. Have fallback to LangChain + OpenAI if ADK proves difficult.

### 🟡 CONCERN: Recap Quality

**Challenge**: Generating spoiler-free recaps that are actually useful requires:
1. Knowing exact plot points per episode (not just synopses)
2. Understanding character arcs up to specific episode
3. Avoiding revealing future events

**Current Approach**: Use GPT-4 with careful prompting

**Risk**: GPT-4's knowledge may be outdated for recent shows, or may hallucinate plot points.

**Mitigation Options**:
1. Use TMDB/TVmaze episode summaries as grounding
2. Add disclaimer: "Recap based on general knowledge - may not be 100% accurate"
3. Allow user to correct/improve recaps over time

## SECTION 6: QUIZ ENHANCEMENT SPECIFICATION

### Problem: Quiz Feels Generic Without Stored Quotes

### Solution: Quote Collection System

**New Data Model - Quote Collection**:
```javascript
{
  _id: ObjectId,
  userId: ObjectId,
  showId: String (TMDB ID),
  showTitle: String,
  quote: String,
  character: String,
  season: Number,
  episode: Number,
  addedAt: Date
}
```

**New User Flows**:

1. **Quote Capture During Viewing**:
   - User: "Remember this quote from Breaking Bad: 'I am the one who knocks'"
   - Agent: "Got it! I'll save that Walter White quote from Season 4. 🗣️"

2. **Quiz from Personal Quotes**:
   - Agent: "Who said this in Breaking Bad? 'I am the one who knocks'"
   - Options: A) Walter White, B) Jesse Pinkman, C) Gus Fring, D) Mike

3. **Community Quotes (Future)**:
   - Pull from public quote databases
   - User's personal quotes + popular quotes mixed

**Implementation Impact**:
- Add P2-007: Quote Save API endpoint
- Add P4-001 modification: Quiz includes quote questions
- Add to agent tools: save_quote(), get_user_quotes()
